# 验证清单

这是发布自托管版本时使用的通用验收清单。不要把真实服务器地址、账号、密码、设备令牌、聊天内容或截图提交到公开仓库。

## 自动检查

```sh
npm ci --ignore-scripts
npm test
npm run check
```

## 首次部署

- [ ] 新服务器按 README 完成初始化。
- [ ] `/healthz` 返回成功。
- [ ] HTTPS 证书有效，HTTP 正确跳转或被反向代理处理。
- [ ] WebSocket 和 SSE 能正常通过反向代理。
- [ ] `data/` 权限只允许服务用户访问。
- [ ] `.data`、`.env`、`data/server.json` 未进入 Git。

## 浏览器与连接程序

- [ ] 能登录、退出和刷新保持会话。
- [ ] 能配对第一台电脑并显示在线状态。
- [ ] 能添加第二台电脑、切换电脑并保持列表隔离。
- [ ] 能按项目查看、搜索、折叠和打开会话。
- [ ] 只展示用户输入和 Codex 最终回复。
- [ ] 能发送文本、续聊、新建对话和上传材料。
- [ ] 任务状态能显示执行中、完成、中断、失败和待确认。
- [ ] 断网恢复后不会重复执行同一条消息。
- [ ] 解绑设备后旧设备令牌立即失效。

## 发布前安全检查

- [ ] 公开仓库没有密码、令牌、生产配置、真实会话和附件。
- [ ] 服务器备份可以恢复，且删除策略经过验证。
- [ ] 反向代理不把后台端口直接暴露到公网。
- [ ] 已向用户说明服务器会处理中继消息、回复和附件。
