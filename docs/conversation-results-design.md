# 结果提醒与新建对话

日期：2026-10-24

## 交互

- 列表上方提供“全部”和“未读结果”筛选，后者按最新最终回复排序，不改变桌面项目归属。
- 每个会话展示最近一轮状态：已完成、正在执行（连接程序实时确认）、已中断、失败、状态未确认；不把缺少结束事件的日志标为已完成。桌面未向连接程序暴露实时轮次时保留“未确认”，不根据残留开始事件猜测仍在运行。
- 最终回复形成独立结果标记，打开并实际显示相应回复、滚到消息底部后标为已读；按账号、电脑、会话隔离，刷新保留。首次接入展示最近 24 小时未读结果，更早结果保留完成标签但不新增提醒；之后保留未读提醒。
- 新建入口位于会话标题旁。用户选择当前电脑的项目，可选标题；成功后进入空白对话，第一条消息通过现有发送与材料上传机制发送。

## 执行

- 电脑以有界日志尾部读取与文件签名缓存提取活动摘要，只同步状态、时间与结果标识，不同步思考或工具内容。
- 新建使用本机 app-server 的 thread/start 及项目参数；通过本机实时项目清单校验归属与工作目录。不得直接写 Codex SQLite 或修改桌面配置。
- 新建具备设备范围、登录、CSRF、操作权限、能力版本及请求去重保护。网络结果未知时通过原请求编号核对，不自动重建。
- 本次只部署服务器和本机连接程序；其他已配对电脑保留原身份，未升级时新建入口明确提示升级。

## 验收

- 单元及接口测试覆盖状态、未读、新建隔离与权限、重复请求、项目参数、空会话。
- 手机尺寸浏览器验证筛选、已读持久化、新结果提醒、新建、离线、旧连接兼容及现有聊天功能。
- 公网通过独立临时会话验证新建、第一条消息与最终回复；保留数据库一致性备份。
