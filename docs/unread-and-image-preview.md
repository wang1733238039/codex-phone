# 未读结果与图片预览

## 行为

未读结果按账号、电脑、会话隔离，保存在当前浏览器。阅读到回复结尾，或发送下一条请求，会确认已有结果已读；新结果不受影响。历史中出现晚于结果的用户回复时，也确认该旧结果已读。后台页面及被弹窗遮挡的聊天不会自动阅读新结果。

已读记录兼容旧的结果标识，另外保存结果时间。同步时同一旧结果的标识变化不会重新提醒；刷新后仍保留已读记录。

图片选择后通过本地 Blob 地址显示草稿缩略图，不必等待上传或电脑接收。刷新后的草稿和已发送图片使用当前账号下的私有附件接口。点击缩略图打开大图，可放大、适应屏幕、下载和重试。图片文件和 Blob 地址不写入 localStorage；草稿移除、发送完成或退出登录后释放本地地址。

服务器 CSP 仅为图片增加 `blob:`，脚本、文件下载和账号隔离规则继续由现有逻辑处理。非图片附件仍使用文件卡片。连接程序无需升级。

## 验证

`node tools/browser-inbox-check.mjs` 在隔离服务器和模拟电脑中覆盖：已有回复确认已读、长回复未看完保留未读、发送下一条清除旧结果、真正新结果再次提醒、旧标识重放与刷新后的已读保持。

`node tools/browser-attachments-check.mjs` 使用真实私有附件接收器，覆盖上传前本地图像、草稿刷新后预览、历史大图、放大、键盘关闭和焦点恢复、草稿隔离及弱网保护。在 375、390、1440 像素宽度检查溢出，截图及报告保存在忽略提交的 `artifacts/`。

上述浏览器回归使用 Edge 的安卓尺寸与触摸模拟，不代表已在用户的夸克浏览器实体手机上完成验收。
