# 修复手机消息和模型列表读取

适用于已有 Windows Codex Phone 连接程序。4090 已在本机更新并验证；7Q 需要在其自己的安装目录应用修复。无需重新配对。

## 交给目标电脑 Codex 的要求

1. 找到这台电脑已有的 Codex Phone 安装目录，确认 `.data/agent.remote.json` 属于本机。备份要替换的源文件，不输出或复制私有配置。
2. 补丁包只提供两份源码：`src/codex.mjs` 与 `src/agent.mjs`。`src/agent.mjs` 是从旧版连接程序提取、仅合入运行状态读取修复的兼容版本；不要把它直接覆盖到已有其他定制改动的源码上。先比较，只合入 `handle('detail')` 的运行状态超时、合并读取逻辑，以及 CodexClient 的二进制查找和启动失败恢复。
3. 保留设备 ID、令牌、服务器地址、Codex home 与所有 `.data` 文件，不删除设备、不复制另一台电脑的配置。
4. 先核查连接程序是否拥有正在执行的独立 Codex 子进程；有则等待或安排保留任务的更新方式，不停止它。桌面拥有的任务可以继续运行，不需要退出桌面 Codex。
5. 本次变更生效需要重新启动这台电脑自己的连接程序。只按 PID、命令行和所属目录确认后重启它；不要结束桌面 Codex 或其他安装的连接程序。
6. 验证网站设备在线、`models` 接口实际返回这台电脑可用的模型、详情接口能读到最新最终回复。打开手机“模型 / 设置”，选择模型和思考强度，确认控件可用。读取验收不要向模型发送额外任务。

## 本次修复

- Windows 桌面升级移除旧程序目录后，后台进程会重新寻找当前安装的 `codex.exe`，保留显式自定义二进制的选择。
- 启动失败的子进程即使只发出 `error/close`、没有 `exit`，后续请求仍能重试，不会永久卡在等待旧进程退出。
- 历史消息先从本地记录读取，运行状态最多等待约 1.2 秒；同会话状态读取合并，较慢的状态返回后通知页面补读。
- 不改变模型发送协议、任务归属或权限，不创建并行模型任务。

网页更新由服务器统一提供。刷新手机页面后，模型入口显示“模型 / 设置”，提供加载状态与“刷新模型列表”；网页重连时会补读消息。若目标连接程序仍旧，单独刷新网页不能修复其运行时。
