# Codex 随行

用户已在会话中确认“手机网页 + 服务器后台 + 电脑连接程序”的方案，并授权实现。

## 实施范围

- 独立子目录，不修改原有项目或 Codex 配置。
- Node.js 24，原生 HTTP、SQLite、WebSocket。中文文件统一 UTF-8。
- 电脑只读本地 Codex 索引和会话文件；通过出站 WebSocket 同步列表和按需读取的历史。
- 手机通过密码登录；HttpOnly Cookie、CSRF 校验、登录限流。电脑连接使用独立随机令牌。
- 服务器缓存会话列表和已打开的历史。电脑离线后可继续阅读缓存；不排队执行离线指令。
- 分类跟随 Codex 已保存的项目，优先真实项目 ID 和显式归属，兼容未完成迁移的桌面映射。置顶独立展示，项目以保存的顺序排列，无项目会话单列；不按月份或目录名代替分类。每条会话只出现一次，归档保持项目分类。
- 手机可折叠项目并记住自己的选择；搜索自动展开匹配分组，刷新保留折叠及键盘焦点。项目分类与会话索引一同缓存，不写入 Codex 原始设置。
- 聊天记录只保留真实用户输入和 Codex 最终回复；思考、工具调用和输出、执行进度、内部上下文不进入可见聊天。通过显示版本使旧缓存失效，服务端过滤后再分页，前端刷新不合并不同版本。
- 续聊采用本机 codex app-server，保留原中转站配置。正在被桌面占用的会话不强制解锁。
- 2026-10-24 续聊修复：输入框不依赖最终回复，离线和运行状态未知也允许写草稿。在线可发送新消息，只有正在提交或重复未确认原文时暂时限制该次提交。
- 任务运行中使用原生 `thread/queue/add` 追加下一轮；本连接拥有当前轮次时可用带 `expectedTurnId` 的 `turn/steer` 补充。队列独立显示，支持取消与显式尝试执行队首。本连接只自动执行自己提交且已到队首的项。
- 模型与 reasoning effort 从本机 `model/list` 读取并验证；桌面独占 writer 时只能跟随会话排队，不伪造模型变更成功。显示运行、结束、中断、失败及未确认状态；历史缺少 final 或结束标记不会被当作永久的发送锁。
- 停止和审批只针对本连接程序启动的任务，不宣称可以接管桌面已有任务。
- 数据目录、电脑令牌、登录资料不进入版本控制或镜像；对话不传到任何第三方服务。
- 2026-10-24 材料上传补齐：附件按用户/电脑/会话隔离，256 KiB 分块，经服务器中转到所选电脑；只在电脑 SHA-256 校验完成后允许提交。直接图片使用原生 localImage，文件提供本机路径，视频可选 ffmpeg 抽帧。附件支持空正文、正常/排队/补充三种发送，保留未知回执保护及独立草稿。未升级电脑继续使用旧有纯文本功能。
- 完整边界、清理策略与验证范围见 `attachments.md`。本次延续已授权的手机网页方案，在现有界面与传输链路内增补，无新第三方上传服务。

## 验证

验证认证、CSRF、恶意消息、缓存离线行为、路径边界、重复发送保护、重连和中文内容；用本机会话做只读检查，并在独立测试会话验证续聊。用手机尺寸浏览器检查布局。

## 执行清单

1. 创建后台、缓存和电脑连接程序。
2. 完成手机优先的列表、搜索、归档、详情、状态和续聊界面。
3. 添加本机一键启动、服务器 Docker/Caddy 部署和连接配置工具。
4. 自动测试、浏览器验证、本机真实会话验证。
5. 交付本地入口；若服务器信息尚未提供，明确所需信息。

## 界面依据

方向：随行。冷白底、深蓝文字、钴蓝操作，列表使用紧凑但可触控的行布局。手机单屏切换列表与对话，桌面双栏。采用系统中英文字体以免移动网络依赖字体服务。

本机未安装 frontend-design、ui-ux-pro-max、impeccable、emil-design-eng，21st/shadcn 工具未提供；采用当前已安装 frontend-design-skill 的规范自行实现。无需照片或付费图像生成。
