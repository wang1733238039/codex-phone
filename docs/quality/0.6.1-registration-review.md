# 0.6.1 注册入口与登录修复

2026-10-25。修复首页只能登录、注册表单只在邀请链接下出现的问题；保留既定的邀请开通服务方式。

## 功能验收

- 首页提供同等可见的“登录 / 注册”切换，登录表单下另有“注册新账号”。
 - 注册页允许输入邀请码或本站完整邀请链接，解释如何获取邀请；邀请链接仍自动打开并移除 URL 中的凭据。
 - 不存在的账号使用管理员正确密码时，旧校验中两边缺少记录触发空值访问；现在显式检查记录并返回通用 401。
 - 登录、注册的意外错误使用通用提示，不把内部字段回传用户；增加回归测试。
 - 手机首屏不主动聚焦密码，避免自动打开软键盘和滚离登录、注册入口。
 - Node 全量 59 项测试通过；Playwright 覆盖首页切换、邀请手动输入、非法邀请、同页邀请、注册、设备与会话、期限和停用恢复，375/390/1440 宽度无横向溢出，无页面脚本异常。
