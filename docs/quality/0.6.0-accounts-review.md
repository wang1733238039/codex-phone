# 0.6.0 账号功能验收

验收日期：2026-10-25。

## 功能与隔离

- 57 项 Node 测试通过，覆盖原有功能及新增 11 项账号集成测试。
- 两个普通账号各绑定两台模拟电脑，复用会话和命令 ID，确认内容、回执和项目快照独立。
- 验证跨账号 API、事件流、附件元数据/内容/删除、命令、模型、审批及设备操作越权均被拒绝。
- 验证邀请单次兑换、邀请撤销/过期、配对归属和电脑上限。
- 验证管理员元数据不包含密码摘要、设备凭据或用户会话内容。
- 验证续期、自然到期自动断开、到期后缓存读取、停用、恢复、密码修改/重置和删除。
- 使用 0.5.0 数据库验证管理员、旧 Cookie、主电脑 ID、设备令牌及中文历史迁移，并实际从迁移前备份重新启动恢复。
- 从仅含发布文件的新目录完成依赖安装、初始化、重复初始化、部署配置生成、健康检查、静态资源与登录退出验收。

## 手机与桌面页面

Playwright 使用独立的管理员与普通用户浏览器上下文，完成邀请生成、注册、首台电脑配对、聊天查看、续期、到期提醒、保留草稿、直接开通账号、停用退出、恢复登录和刷新保持登录。375、390、1440 像素宽度无横向溢出，无页面 JavaScript 异常。截图保存在私有 `artifacts/accounts/`，不进入开源仓库。

本次沿用现有产品视觉系统。环境中没有 ui-ux-pro-max、impeccable、taste、soft、emil-design 或 redesign 技能，也没有接入 21st 组件服务；原生表单和对话框足够覆盖已有页面内的账户管理，未新增 UI 依赖。

## 发布边界

本版提供邀请制账号和人工开通/续期，不包含支付网关、自动扣费、短信/邮件找回或公开无邀请注册。不将本地模拟验证描述为真实客户或大规模容量测试，也不把 GitHub 同步当成生产部署证明。
