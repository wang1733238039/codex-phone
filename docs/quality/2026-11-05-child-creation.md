# 手机新建子对话验收

日期：2026-11-05；版本：0.6.10。

## 原因与修复

实际失败回执显示，按 `attachToSource: true` 创建原生子对话时，父对话由桌面持有写入权，Codex 拒绝操作。原页面也缺少创建回执恢复，结果不确定时会持续禁用按钮。

优先保留原生附着方式；仅在收到明确且无副作用的 writer 拒绝时，创建 `attachToSource: false` 原生分支。随后核验原生日志元数据中的 `forked_from_id`，保存到本机私有关联清单，等待索引确认后交付手机。超时或其他不确定结果不自动再次创建。

普通分支可能进入桌面普通会话列表；手机按已核验关系分组，不修改 Codex 自身数据库。临时侧栏不支持继续分支，返回主对话创建。

## 用户流程

在公开站点以 390 × 844 手机视口登录，使用独立验证主对话：

1. 保持父对话由另一个原生进程持有，模拟实际 writer 占用。
2. 打开“子对话”，点击“新建子对话”，确认自动进入可编辑的新对话。
3. 发送两条只需文本回复的验证消息，分别等待真实模型最终回复。
4. 刷新页面，切回主对话，再切回子对话，两条结果均保留。
5. 确认原父对话仍可由原进程读取。

浏览器回归覆盖 375、390、1440px，无横向溢出；对话入口触摸高度 44px，标题区域约 84px。另模拟创建成功但 HTTP 回复丢失，刷新后查询同一请求并打开同一个子对话，原生创建计数仅增加一次。明确拒绝时显示错误并允许重试。

结果：97 项自动测试通过，16 项浏览器流程检查通过；部署后的公网两轮真实回复、任务完成状态、再次新建按钮可用均通过。手机视口由本机 Chromium 模拟，本次未操作实体安卓手机。
