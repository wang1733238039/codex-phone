# Windows 连接端 0.5.1 验收

2026-10-27。服务端保持 0.6.2。新增 Windows 桌面和开始菜单入口，复用原安装目录、配对配置、后台连接进程与守护，不迁移设备身份。

## 使用与验证

- 配对后运行 `node tools/install-connector.mjs`，安装当前用户登录自启与桌面/开始菜单快捷方式。
- 管理窗口打开时按需启动守护；关闭窗口不停止连接。自启勾选只改变登录启动项，取消勾选不停止当前任务。
- “运行中”仅指本机连接进程存在；服务器真实在线状态仍由手机电脑列表确认。
- 实机验证关闭自启、重新开启自启不改变现有连接进程。中文路径中的独立无网络 fixture 验证首次手动启动与重复启动仍只有一个连接/守护，并确认其他安装目录不能移除原自启项。
- Windows PowerShell 5.1 运行中文脚本使用 UTF-8 BOM；本机配对配置和日志不进入分发包。
- 以 Windows 原生窗口渲染检查布局与中文文本。自启项已安装并启用；本次未执行真实注销或重启，不能把自启注册验证写成重启恢复实测。
- 桌面快捷方式真实打开管理窗口，原连接进程保持不变。全量 62 项 Node 回归与语法检查通过，分发 ZIP 确认含管理窗口和安装脚本且中文脚本保留 UTF-8 BOM。
