# 子对话发送与新建：本地验收

日期：2026-11-04。此文补充 2026-10-29 的只读方案，替代其“子对话一律只读”和“无子对话隐藏入口”的行为。

## 实现

- 标题区域保留子对话入口，即使没有子对话，也可进入面板新建。
- 在当前选中的会话下新建原生附属分支，继承上下文与权限；使用 `thread/fork` 的 `attachToSource:true`，不写 Codex 数据库、不伪造父子关系。
- 本机历史存在、未归档且通过完整祖先校验的子对话可通过现有发送链路续聊。桌面持有时优先原 owner 通道，沿用排队、补充、停止与审批验证。
- 原生明确声明不接受直接输入时拒绝执行并提示返回父对话；不绕过原生限制。
- 新建后验证 SQLite 原生父子关系再回传。超时结果不明时禁止页面重复点击，避免重复创建。服务端请求编号按父会话和设备校验。
- 旧连接程序未声明 `childControls` 时保留只读；归档、孤立、历史不在本机的子对话不可操作。

## 验证证据

- 在独立临时 CODEX_HOME 中调用实际 Codex 0.166.0-alpha.5.1：创建空父会话、设置名称并卸载，再创建原生附属分支。SQLite 索引识别到正确父 ID、深度 1、`local:true`，原生返回 `canAcceptDirectInput:true`，子历史可读取。未调用模型，未向真实会话发送消息。
- 浏览器构造连接测试通过 14 组场景，包括子对话发送、新建后切换到可编辑子对话、旧连接只读、离线、晚到响应、草稿与滚动位置恢复。
- 375/390/1440px 无横向溢出，入口触摸高度 44px，头部约 84px，控制台无异常。报告：`artifacts/children/browser-report.json`。
- 全部 Node 回归通过 89 项；随后增加原生不接受输入的保护测试，重新运行桌面、来源与子对话相关 33 项全部通过；14 组浏览器场景再次通过。

## 发布边界

用户确认发布后，已部署服务器 0.6.8 并更新本机连接程序，保留服务器数据与配置及部署前备份。发布前全部 Node 回归 90 项通过。线上手机宽度检查确认子对话入口显示、新建按钮可用、输入可编辑，无横向溢出和控制台错误。其他电脑须更新连接包才开放子对话操作。

发送链路使用构造连接与适配器回归验证，尚未用真实模型在桌面子对话执行任务；不把此测试宣称为真实模型端到端验收。原生附属分支要求本地持久化、分页历史，旧版本或不兼容会话会返回原生错误，不降级创建普通根会话。
