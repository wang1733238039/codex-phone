# 0.6.2 自助注册验收

2026-10-26。按用户指定方案，将默认注册改为填写账号和密码、直接创建数据库账号并登录，不需要邀请或审批。沿用现有服务期限的 30 天默认值、3 台电脑默认上限及账号隔离；密码保存加盐 scrypt 哈希。

## 功能与边界

- 首页“登录 / 注册”和“注册新账号”入口可用，注册表单只有账号、密码和确认密码；两次密码不一致时明确提示。
- `POST /api/register` 无邀请码即可创建普通账号；新账号没有任何电脑和他人会话。
- 请求中的角色、归属、期限和设备额度不改变服务端规则。用户名大小写归一，重复注册返回 409，并发注册不会产生部分账号或审计记录。
- 原邀请链接继续兼容，单次兑换和撤销规则不变。数据库 schema 仍为 3，不需要重建数据库。
- 62 项 Node 测试、语法检查及手机浏览器注册、退出重登、设备配对、会话、续期、到期和停用恢复回归通过。
- 注册尚不校验付款，不包含在线支付、自动扣款或邮箱验证。新注册默认开通 30 天，后续由管理员续期。

使用 brainstorming 对齐已明确的用户方案，使用 frontend-design-skill 检查原有移动页面。未安装的 ui-ux-pro-max、impeccable、taste、soft、emil-design-eng、redesign 及不可用的 21st 组件服务不作为依赖，复用产品现有原生表单与样式，无新增资源请求。
