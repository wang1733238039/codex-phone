# 手机端子对话切换：本地验证

## 已确认范围

用户已确认先在本地实现和测试，验收结果交由用户确认后，才可部署服务器或同步 GitHub。

首轮实现主会话内查看、切换子对话，并显示从日志取得的状态。子对话只读，禁止发送、停止、审批、排队修改和上传。主会话保持原有操作能力。不得启动子 Agent、向真实会话发送测试消息、重启线上连接程序或修改 Codex 数据库。

## 交互

在原有标题行加入 44px 触摸入口。主会话显示子对话数量；子对话显示切换入口。点击打开原生模态抽屉，列出主会话和关联子对话，显示当前项、名称、层级及状态。手机抽屉限制高度并独立滚动，桌面使用居中弹窗。没有子对话时隐藏入口。

子对话隐藏输入区，底部显示只读说明和返回主对话按钮。切换保留每个会话的草稿和阅读位置，按账号、设备、会话分别保存。浏览器后退、直接链接、设备切换、异步响应均需验证。

## 数据与隔离

连接端以 `source.subagent.thread_spawn.parent_thread_id`、`thread_spawn_edges` 和明确的 attached parent 字段建立关联；不使用标题或工作目录猜测。排除 guardian、孤立子对话和循环关系。父子关系的 open/closed 字段不代表执行状态。

快照保留原有主会话 `threads`，新增可选 `childThreads`；服务器在原有账号、设备作用域内保存和校验关系，主列表及其计数始终只包含主会话。新增 family 查询返回同一主会话下的关联列表。旧连接程序缺失新字段时按空列表处理。

现有转录投影只传任务输入与最终回复。继承的父会话历史需要按元数据边界剔除，缺失指令时不从思考或工具调用拼凑。

## 验收

1. 单元与 HTTP 测试覆盖真实父子关系、嵌套、孤立、循环、guardian 过滤和旧协议兼容。
2. 验证子对话的读取、离线缓存、权限、账号及设备隔离，操作在服务器和连接端均拒绝。
3. 浏览器在 375、390 和 1440px 宽度测试切换、草稿、滚动位置、直接链接、快速切换、错误恢复、键盘和无横向溢出。
4. 只读接入本机真实 Codex 数据，使用独立本地服务和测试数据库；不发送真实任务。
5. 保存截图与测试报告，明确真实数据检查和模拟数据检查的区别。用户确认前不部署、不推送。
